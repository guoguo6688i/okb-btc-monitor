# OKB/BTC 五因子信号自动监测

基于 OKX 公开 API 的 OKB/BTC 交易对量化择时工具，每4小时自动运行，信号变化时发送邮件通知。

## 五因子模型

| 因子 | 权重 | 说明 |
|------|------|------|
| 估值 | 30% | OKB/BTC 比率近3年历史分位 |
| 事件 | 25% | 重大催化事件（X Layer升级、Jumpstart等） |
| 技术 | 20% | RSI + 布林带 + MA50偏离 + 量比 |
| 趋势 | 15% | BTC MA50/MA200排列 |
| 情绪 | 10% | 永续资金费率反向 |

## 信号阈值

- ≥80：强买入
- 70-79：买入
- 55-69：观望偏多
- 40-54：持有/观望
- 25-39：减仓
- <25：卖出

## 配置

在 GitHub Secrets 中配置：

- `SMTP_PASSWORD`：QQ邮箱授权码（不是登录密码）

## 本地运行

```bash
pip install requests
python check_signal.py
```

## 注意事项

- OKB 总量已永久固定为2100万枚（2025年8月起），不再有季度销毁
- 事件因子需手动添加重大催化事件
- 仅供研究参考，不构成投资建议
